# 最小可打开模板结构规范（Axure RP 9/10）

> 目标：提供一份**最小可打开**的模板规范，便于你在本地 Axure 中快速搭建并“一键另存”为正式 `.rp` 文件。
> 说明：本规范强调“结构最小化 + 可执行步骤”，不依赖插件与外部脚本。

## 1. 适用范围

- Axure RP 9 / Axure RP 10（Windows/macOS）。
- 适用于本仓库党支部活动管理原型。
- 输入数据使用：
  - `party-branch-activity-pages.csv`
  - `party-branch-activity-ledger.csv`
  - `party-branch-activity-flow.csv`

## 2. 最小工程结构（逻辑层）

在 Axure 中创建一个新工程后，仅保留以下页面即可满足“可打开 + 可演示 + 可另存”：

1. `00_封面`（可选但建议）
   - 标题：党支部活动管理原型
   - 版本：v0.1
   - 日期、作者
2. `01_活动台账`
   - 筛选区（活动类型、时间、审批状态、关键词）
   - Repeater 表格区（导入 ledger.csv）
3. `02_新建活动`
   - 基础信息、参与信息、经费信息、成效信息
   - “实际支出确认后同步党费台账”规则提示
4. `03_审批流配置`
   - Repeater 流程节点区（导入 flow.csv）
   - 三类流程说明（无经费 / <=10000 / >10000）

## 3. 母版与样式（最小集合）

为保证“最小可打开”，仅建议创建以下 4 个母版（可选，但推荐）：

- `M_Header`：页面标题与说明。
- `M_SideNav`：左侧导航（台账/新建/审批流）。
- `M_Tag`：状态标签（通过/审批中/待同步）。
- `M_RuleNotice`：规则高亮块（党费台账联动说明）。

颜色建议（与 `index.html` 保持一致）：

- 主色：`#d7263d`
- 成功：`#1f9d55`
- 警告：`#f59e0b`
- 危险：`#dc2626`
- 背景：`#f5f7fb`

## 4. 数据导入最小步骤（关键）

### 4.1 活动台账页

1. 插入 Repeater（命名：`rpLedger`）。
2. 右键 Repeater → Import Data from File。
3. 选择 `party-branch-activity-ledger.csv`。
4. 在 Item 中放置文本控件，映射列：活动名称/时间/参与情况/实际支出/审批状态/联动状态。

### 4.2 审批流页

1. 插入 Repeater（命名：`rpFlow`）。
2. 导入 `party-branch-activity-flow.csv`。
3. 映射列：流程类型、条件、节点顺序、节点名称、处理角色、输出结果。

### 4.3 组件字典（可选增强）

1. 在任意页面插入 Repeater（命名：`rpDict`）。
2. 导入 `party-branch-activity-pages.csv`。
3. 用于快速查阅“页面-模块-组件”结构，不参与最终交互也可。

## 5. 业务规则最小实现（交互）

在 `02_新建活动` 页面至少配置以下逻辑：

1. 字段：`实际支出`（数字输入）。
2. 按钮：`确认支出`。
3. OnClick 逻辑（最小版）：
   - 若实际支出 = 0 → 显示“无需审批/无需同步”。
   - 若 0 < 实际支出 <= 10000 → 显示“书记审批后同步党费台账”。
   - 若 实际支出 > 10000 → 显示“多级审批通过后同步党费台账”。

> 注：最小模板可只做文本提示，不强制实现完整流程跳转。

## 6. 一键另存流程（你本地执行）

1. 打开 Axure，新建工程。
2. 按本规范创建页面与 Repeater 并导入 3 份 CSV。
3. `File -> Save As`。
4. 命名为：`党支部活动管理-最小模板.rp`。
5. 再次关闭并双击打开，确认“可打开”。

## 7. 打开验收清单（DoD）

满足以下 6 条即可认为“最小可打开模板”完成：

- [ ] `.rp` 文件可双击打开无报错。
- [ ] 至少 3 个业务页面存在（台账/新建/审批流）。
- [ ] `ledger.csv` 成功导入并显示至少 3 行。
- [ ] `flow.csv` 成功导入并显示至少 12 行。
- [ ] 页面中明确展示“实际支出确认后同步党费台账”规则。
- [ ] 页面中明确展示按金额分级审批规则。
